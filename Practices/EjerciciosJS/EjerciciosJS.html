Mira la consola con F12

Ejercicios:

Variables

Suma de dos números: Solicita al usuario dos números y muestra la suma de ellos. Cálculo del área de un rectángulo: Pide al usuario que ingrese el ancho y la altura de un rectángulo y muestra el área. Conversión de temperatura: Pide al usuario que ingrese una temperatura en grados Celsius y conviértela a Fahrenheit, mostrando el resultado.

Funciones:

Calculadora básica: Crea una función que acepte dos números y una operación (suma, resta, multiplicación o división) y devuelva el resultado. Factorial de un número: Define una función que calcule el factorial de un número ingresado por el usuario. Verificar número primo: Escribe una función que determine si un número ingresado por el usuario es primo o no.

Variables y Funciones:

Promedio de tres números: Crea una función que acepte tres números como parámetros y devuelva su promedio. Área de un triángulo: Define una función que calcule el área de un triángulo utilizando la fórmula: 0.5 * base * altura. Convertidor de moneda: Crea una función que convierta una cantidad de dinero ingresada por el usuario de una moneda a otra, utilizando un factor de conversión predefinido.
